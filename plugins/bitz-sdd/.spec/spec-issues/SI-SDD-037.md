- **目的**: `sdd-core/references/parallel-git.md` のブランチ規約に次の1行がある。

  > requirements/ への変更（採番・状態遷移）は **main 直コミット**または最優先マージ。
  > 契約は全ブランチから同一に見えること

  一方、bitz-env が展開するガードレール（および本リポジトリの `AGENTS.md`）は
  **「デフォルトブランチへの直接コミット」を禁止**しており、`.claude/settings.json` の
  permissions と PreToolUse フックで機械的にブロックする。同じプラグイン群が配布する
  規律が互いに矛盾している。

  実務上の影響は小さくない。この行は「採番と status 遷移は直列化したい」という
  正しい要求（`SDD-FR-144` の Plan 直列化と同じ動機）を、**禁止された手段**で満たすよう
  指示している。ガードレールが有効な環境ではブロックされて手が止まり、無効な環境では
  ガードレールを破る運用が定着する。

  `SDD-FR-165`（本 spec-issue の起票元となった実装）で同じ節の直下へ「ブランチは既定
  ブランチのリモート追跡から明示的に切る」規律を追記したため、**同一節の中で矛盾が
  隣接して見える状態**になった。
- **提案する修正**:
  1. 当該行を、禁止された手段に依存しない形へ書き換える — 「採番・status 遷移は
     専用ブランチで**直列に**行い、**最優先でマージ**して全ブランチから同一に見える状態を
     早期に回復する」。`SDD-FR-144` の Plan 直列化・integration preflight と整合させる
  2. 併せて、`parallel-git.md` の既存節が前提する「隔離された作業者」モデルと、
     `SDD-FR-165` で追記した共有作業ツリーの規律の関係を整理する
  3. ROADMAP の V4 テーマ4 は「`parallel-git.md` の混在責任を責任に沿った文書へ再編し、
     デフォルトブランチへの直接コミットを許す古い記述を廃止する」と既に宣言している。
     本件をその再編の一部として扱うか、**矛盾の解消だけ先行**させるかは裁定点
- **対象ファイル**: `skills/sdd-core/references/parallel-git.md`、
  関連する SDD-FR 要件（ブランチ規約を逆起票しているものがあれば併せて改訂）。
- **確認観点**: 書き換え後も「契約は全ブランチから同一に見える」という元の要求が満たせること。
  `SDD-FR-144`（採番の直列化・integration preflight）と矛盾しないこと。
  bitz-env のガードレール（禁止事項の節）と一致すること。
- **影響推定・ロールバック**: 文書1行の書き換えが中心で加法的。ロールバックは revert のみ。
  ただし ROADMAP の V4 再編と対象が重なるため、先行させる場合は再編時の二重作業になる
  （矛盾を残す期間とのトレードオフ）。
- **依存**: `SDD-FR-165`（本 spec-issue の起票元。同一節へ規律を追記した）、
  `SDD-FR-144`（採番・status 遷移の直列化の正）、ROADMAP V4 テーマ4
  （`parallel-git.md` の再編と `sdd-git` 廃止）、bitz-env のガードレール契約。

## 予備判定（推薦）— 裁定は人間専用

| 判定軸 | 確認結果 |
|---|---|
| 既存要件との矛盾 | あり（解消対象）。bitz-env ガードレールと `parallel-git.md` が矛盾している |
| ガードレール抵触 | なし。むしろガードレールとの矛盾を解消する |
| 影響範囲 | sdd-core の規律文書1行。ROADMAP の V4 再編と対象が重なる |
| 軽量レーン適否 | 可（文書の書き換え。公開 API・スキーマ・frontmatter 書式に触れない） |

**推薦: accept し、矛盾の解消だけ先行させる**。ガードレールで機械的にブロックされる手段を
配布物の規律が指示している状態は、利用者の手を止めるか規律を破らせるかのどちらかにしかならない。
V4 の `parallel-git.md` 再編を待つ理由は「二重作業を避ける」だけであり、1行の書き換えに対して
矛盾を残す期間のコストが上回る。再編時にこの行を責任に沿った文書へ移すのは差分の小さい作業である。
