## 2. 裁定

### 2.1 M2 是正予算 — **段階承認（P3）**

**まず 4 PR / 13 session を承認する。**

- session 上限は根拠が無いため、**M2 実装枠の比率**（6 PR / 20 session ≒ 3.3 session/PR）を
  暫定適用して 4 PR × 3.3 ≒ **13 session** とした。実績記録後に再校正する
- `SI-FLW-061` → `SI-FLW-057` の2件を通した時点で、**残り（`058` / `059` / Exit 再レビュー）を
  実績つきで再提示**する
- 総額を先に固めない。見積もり根拠が無い状態で総額を決めると、M0 / M2 と同じ経過をたどるため

### 2.2 PR の定義 — **裁定・調査・記録の PR は budget 外**

milestone budget が数えるのは**実装 PR だけ**とする。
裁定材料の作成、裁定記録、調査、spec-issue の起票・裁定反映は budget の外に置く。

理由: 2026-08-15 の6 PR が示すとおり、裁定プロセスは実装とは独立に発生する。
これを実装枠に含めると、裁定が進むほど実装枠が枯れて milestone が止まる。

なお**出荷面の是正（#275）は実装 PR**であり、本定義では budget 内に属する。
本裁定より前の消化分は遡って計上しない。

### 2.3 付帯条件

1. **run manifest の記録を着手条件とする。**
   最初の PR（`SI-FLW-061`）に `SI-FLW-058` の一部として run manifest の記録機構を含め、
   以後の PR で実績 PR 数・session 数・レビュー修正回数・出口未達理由を記録する。
   次の再提示はこの実績に基づいて行う（`SYN-015` の是正）。
2. **着手順を `SI-FLW-061` → `SI-FLW-057` に固定する。**
   両者は同じ `worktree_runtime.apply()` を触るため、承認経路を縮退させてから
   例外分類を当てる方が触る面が小さくなる。
3. **予算到達時は自動停止し人間へ再提示する。**
   4 PR または 13 session のどちらかを先に使い切った時点で停止し、
   継続 / scope 縮小 / No-Go を再裁定する。進行中の上限を暗黙に延長しない
   （ROADMAP の既定規則を今回も明示適用する）。

### 2.4 M3 移送分の計上は**行わない**

`SI-FLW-060` と `finish` / `discard` 実装の M3 budget への加算は本裁定に含めない。
M3 着手前に改めて裁定する。現在 `FLW-DSN-014` の M3 budget（8 PR / 26 session）は
**移送分を未計上のまま**である旨が明記されている。
