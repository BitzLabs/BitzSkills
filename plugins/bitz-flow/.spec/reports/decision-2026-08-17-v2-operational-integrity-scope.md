# BitzFlow V2 — 強い改ざん耐性をスコープ外とする裁定

- **日付**: 2026-08-17
- **裁定者**: hide
- **対象**: M2 receipt の真正性保証、`SI-FLW-072` の真正性アンカー提案
- **裁定原文**: 「強い改ざん耐性 については、無しとしましょう。通常の運用が可能なものを目指します。将来的に必要に駆られたら、その時に考えます」
- **記録者**: codex（裁定者の明示指示に基づく代行記録・実行者未検証）

## 裁定

1. BitzFlow V2 は、receipt store と保護境界の双方を操作できる攻撃者に対する真正性、
   非否認、改ざん後の復元可能な ground truth を提供しない。
2. M2 が扱うのは通常運用で生じる receipt の破損・不整合、worktree の生成・消失、
   binding 不整合の検出と安全側への停止である。これらの検出は維持する。
3. HMAC・外部タイムスタンプ・外部アンカー・専用鍵管理など、強い改ざん耐性を実現する
   仕組みは V2 の要件・設計・Completion Gate の前提に含めない。
4. 将来この保証が必要になった場合だけ、脅威モデル、信頼境界、鍵と復旧運用、費用を含む
   新規の discovery / security 設計として改めて裁定する。

## SI-FLW-072 への影響

`SI-FLW-072` に含まれる「整合的に再計算された receipt の偽装」および外部アンカーの
提案は対象外とする。一方、公開経路の固定値、schema と実装の乖離、通常運用での
読み取り不能・binding 不整合の誤分類は別の運用品質の問題として open のまま扱う。
