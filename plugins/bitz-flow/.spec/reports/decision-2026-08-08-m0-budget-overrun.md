## この再提示は安全弁が初めて働いた例である

`FLW-DSN-014` の timebox は当初から「5回の作業session または 1PR で出口に到達しない場合は
scope/pivot を人間へ再提示する」と定めていたが、**M0 の 17 PR を通じて一度も発動しなかった**
（`FLW-REV-006` SYN-003 / GP-001）。本裁定は、GP-001 で残予算を明示し直したうえで
**超過を検知して再提示した最初の記録**である。

`SI-FLW-027` で予算の記録先（run manifest の `budget` ブロック）が定数だった問題も是正済みで、
以後は残予算・裁定記録の参照が実測の成果物へ残る。

## 裁定材料 — 残予算の消費実績

| 枠 | 予算 | 計画していた用途 | 実際に使った PR |
|---|---:|---|---|
| 実装 | 1 PR | `SI-FLW-018` 対策 | **#178**（計画どおり） |
| 検証 | 1 PR 目 | 測定系 blocking（GP-003 / 004 / 005）の消化 | **#177**（計画どおり） |
| 検証 | 2 PR 目 | **第11ラウンド実測と出口判定** | **#179**（計画外） |
| session | 10 | — | 1（本セッション連続） |

**3/3 を消費し、本来の用途だった第11ラウンド実測が残っている。**
実測とその結果コミットは4本目の PR となり、超過する。

### 超過の原因 — #179 の内訳

| 内容 | 性質 |
|---|---|
| `--harness-retries` が claude-code / antigravity へ未到達 | **#177 の消化漏れ（手戻り）** |
| `SI-FLW-027`（run manifest の予算ブロックが定数） | **新規発見**（10ラウンド気づかれなかった既存欠陥） |
| 所要 trial 数を runner が仕様から読む / v2 を 21 へ調整 | 実測に必要な準備 |

`FLW-DSN-014` は「レビュー修正は元PRへ含め、機械的な再実行だけではsessionを加算しない」と
定めており、**手戻り分は本来 #177 に含まれるべきものだった**。#177 が既にマージ済みで
あったため別 PR になっている。すなわち #179 は**純粋な新規消費ではない**。

### 分類そのものが実態と合っていなかった

GP-001 は予算を「実装 / 検証」の2区分へ分けたが、M0 実績で最大のカテゴリは
**測定系の構築・是正（7 PR）**であり、これは「eval 反復（3 PR）」とは性質が違う。

- 測定系の是正 … 計測器そのものを直す。**やるまで欠陥の存在も規模も分からない**
- eval 反復 … 決めた条件で回して測る。**回数を見積もれる**

残予算の検証枠はこの2つを1つに混ぜており、`SI-FLW-027` のような新規発見が1件出た時点で
**枠が足りなくなるのは構造的だった**。GP-001 の再校正は一段粗かった。

## 裁定 — (a) 検証予算 +1 PR で継続する

**accept。** 根拠は次の3点。

1. **超過分の半分は手戻りであり、新規消費ではない。** #179 のうち `--harness-retries` の
   未到達は #177 の消化漏れで、規約上は元 PR に含めるべきものだった。
2. **blocking は全消化済みで、残るのは実測 1 回だけである。** `FLW-REV-006` の
   GP-001〜GP-005 はすべて解消し、`SI-FLW-018` の対策も入っている。
   ここで止めると、**測定系の是正に費やした 7 PR の成果を一度も測らずに終わる**。
3. **scope 縮小は費用対効果が合わない。** `FLW-DSN-014` の縮退出荷境界へ切り替えても、
   M0 read-only prerelease を維持するだけで「write 機能へ進む前に単一 dispatcher の価値を
   検証する」という M0 の目的は未達のまま残る。実測 1 回の追加より失うものが大きい。

### 改訂後の M0 残予算

| 枠 | 予算 | 用途 |
|---|---:|---|
| 検証（eval 反復） | **1 PR** | 第11ラウンド実測と M0 出口判定 |
| session | 4（累計 14） | |

**次の超過では scope 縮小を第一候補とする**（GP-001 の方針を維持する）。
実測が未達に終わり追加の是正が必要になった場合も、是正を自動的に続行せず再提示する。

### 予算区分の是正は行うが、M1 以降へ適用する

「測定系の構築・是正」と「eval 反復」を分ける区分の見直しは妥当だが、
**M0 の残り 1 PR に対して区分を作り直しても意味が無い**。M1 開始時の再校正
（`FLW-DSN-014` が定める手順）で3区分へ改める。M0 は現行の2区分のまま閉じる。

## 採らなかった案

- **(b) scope 縮小**: GP-001 は「次は第一候補」としたが、上記3の理由で今回は採らない。
  **次の超過では第一候補のままとする**
- **予算区分の再設計を先に行う**: M0 の残り 1 PR には効かず、実測を後ろ倒しにするだけ
- **一旦停止して open 5 件へ移る**: `SI-FLW-019`（測定系の恒久化）は測定系の是正が
  正しく効いたかを**実測で確かめてから**設計したほうが材料が揃う。順序が逆になる

## 裁定しなかったこと（本裁定の範囲外）

- **M1〜M5 の予算は変更しない**（GP-001 の再校正値を維持。区分の見直しは M1 開始時）
- **出口条件は変更しない**（`SI-FLW-026` の裁定を維持）
- **予算消費の自動集計は行わない**（bitz-sdd テーマ13-E の裁定待ち。
  `SI-FLW-027` で「事実でない値を書かない」ところまでは是正済み）
- **`SI-FLW-019` / `SI-FLW-006` / `SI-FLW-022`〜`024` は未裁定**
