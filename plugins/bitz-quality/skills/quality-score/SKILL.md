# quality-score

`quality-score` は、**5軸リスクスコアリングモデル**に基づき、施策ごとのリスクを定量評価して適切な QA 関与レベル（レベルA/B/C）を自動判定するスキルです。

## 1. 5軸評価モデルの定義

| 軸 | 項目 | スコア 1（低） | スコア 2（中） | スコア 3（高） |
|---|---|---|---|---|
| **scale** | 開発規模 | 小規模（< 100行） | 中規模（100〜500行） | 大規模（> 500行） |
| **security** | セキュリティ | 影響なし | 参照のみ | 認証・認可・暗号・決済・PII変更 |
| **blast_radius** | 影響範囲 | 局所的モジュール | 複数モジュール連携 | コア共通基盤・DBマイグレーション |
| **complexity** | 難易度 | 定型・単純処理 | 標準ビジネスロジック | 非同期・並行性・複雑状態遷移 |
| **familiarity** | 習熟度 | チームが熟知 | 標準的な領域 | 初見ドメイン・新技術スタック |

## 2. 関与レベルの判定基準

- **レベル A（Full QA）**: 合計スコア `12〜15点`、または **セキュリティ/影響範囲が 3** の場合
  - 専門サブエージェント群によるフルテスト設計（影響・観点・ケース・データ）
  - 3層品質ゲート（静的チェック + LLM多観点レビュー）の完全適用
- **レベル B（Review QA）**: 合計スコア `8〜11点`
  - テスト観点一覧の作成と、人間またはQAエージェントによる重点査読
- **レベル C（Self QA）**: 合計スコア `5〜7点`
  - 開発者によるユニットテスト実装とセルフチェック（静的ゲート通過必須）

## 3. 実行手順

同梱スクリプト `<このスキル>/scripts/quality_score.py` を実行してスコアリングを行います。

```bash
# 施策のリスク評価と .spec/quality/scorings/ への保存
python3 <このスキル>/scripts/quality_score.py FEATURE-001 \
  --scale 2 \
  --security 1 \
  --blast-radius 2 \
  --complexity 2 \
  --familiarity 1 \
  --details "新規ユーザー設定項目の追加" \
  --save
```

## 4. 規律

- **クリティカル軸の重視**: セキュリティやDB変更（スコア3）を含む施策は、合計点に関わらず自動的にレベルAと判定される。
- **評価根拠の記録**: 成果物は `.spec/quality/scorings/` に永続化し、後続の `quality-core` やレビューの判断材料とする。
