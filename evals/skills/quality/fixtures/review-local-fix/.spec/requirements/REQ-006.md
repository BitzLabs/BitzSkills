# REQ-006 内部入力関数が既存の空文字と非空文字の契約を満たす

## Intent

単一モジュール内の非公開helperの既存契約を修正する。外部公開APIの変更ではない。
入力は文字列に限定し、依存、CI、永続化、資格情報を扱わない。本例のapprovedは合成された承認済み状態である。

## Acceptance Criteria

- [REQ-006:AC-01] [ACTOR:TargetSystem] [WHEN] 空文字を受け取った場合 [MUST] [THEN] 「empty」だけを含む1要素のリストを返す。
- [REQ-006:AC-02] [ACTOR:TargetSystem] [WHEN] 非空文字列を受け取った場合 [MUST] [THEN] 要素のないリストを返す。

## Verification

固定Python試験の実assertと実行結果から、空文字、非空ASCII、非空日本語の内容を確認する。
文字列以外の入力はこの契約の対象外である。
