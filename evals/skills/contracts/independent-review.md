# 独立検分の契約

独立検分は、実装を行ったエージェントの継続ターンをそのままレビューへ読み替えない。新しい実行を作り、
`independent-review.schema.json`に従って次を記録する。

- 実装実行とレビュー実行の識別子、対象コミット、差分の範囲
- レビューへ渡した入力と、意図した答えや作業者の結論を渡していないこと
- レビュー実行が新しい文脈で、実装側の非公開履歴を継承していないこと
- レビュー者が直接確認した差分、Core結果、再実行した検査
- 再実行できなかった検査と理由

新しい文脈、入力の分離、対象の確定のいずれかを証明できない場合、`independent`は`false`である。
その結果は所見として利用できるが、独立検分を要求するGateの合格証拠にはしない。

記録は`validate.py review --input <record.json>`で検査する。
JSON Schemaの構造検査に加え、`independent: true`の実装IDとレビューIDが異なることを検査する。
Schema単独では任意の2フィールドの同値を検査できないため、このコマンドを省略しない。
検査の通過は記録の整合性を示し、記録した独立性の事実そのものを保証しない。
