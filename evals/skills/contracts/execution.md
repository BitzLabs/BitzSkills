# 検証コマンドの実行契約

`verify`または独立レビューで登録テストを起動する前に、次を秘密の値を読まずに確認する。

1. 公開設定の引数列テンプレート、作業ディレクトリ、起点から到達するテスト対応
2. 登録コマンドと関連テストの差分
3. 想定する書込み先、ネットワーク、資格情報へのアクセス
4. 実行ホストの隔離と権限が利用者の依頼範囲へ限定されていること

危険な変更、範囲外の書込み、外部送信、秘密へのアクセス、または十分に制約できない副作用が残る場合は
実行を止める。登録済み、シェルを介さない、静的にコマンド名を確認した、という事実だけを安全の根拠にしない。

Core 1.0は展開後の正確な`argv`を実行前に返す公開操作を持たない。正確な`argv`の事前確認が安全上必要な
ケースでは、`verify`を実行せず`stop`とする。Phase 0ではCoreへ計画操作を追加しない。必要性が評価で確認された場合は、
Coreの公開契約を変更する別の決定記録を先に作る。
