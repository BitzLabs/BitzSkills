# 検討資料の位置づけ

本ディレクトリの文書は、次期設計に至るまでの調査、仮説、旧案を保存する**非規範資料**である。

- 現在の設計判断やEARS-AI正式規格の根拠として直接使用しない。
- 「タグがLLMのAttentionを固定する」「LLM出力を決定論化する」「ハルシネーションを排除する」などの
  記述は未検証の仮説であり、製品保証ではない。
- AIエージェントの通常コンテキスト収集対象から除外する。
- 現在の正は[軽量設計](../02.設計書/README.md)と[EARS-AI統合規格](../03.詳細設計/01_EARS-AI規格/README.md)である。
- 旧表現を移行するときだけ、元資料として読み取り専用で参照する。

保持理由は[ADR-001](../02.設計書/10_決定記録/ADR-001_EARS-AI旧検討版の位置づけ.md)を参照する。
