# ADR-001: EARS-AI旧検討版（v2/v3/v5）の位置づけ

- 状態: Accepted
- 決定日: 2026-08-25
- 関連: [EARS-AI規格/07_適合性・バージョン・移行仕様.md](../../03.詳細設計/01_EARS-AI規格/07_適合性・バージョン・移行仕様.md)

## 背景

`01.検討資料/` にはEARS-AIの第2版、第3版、第5版を名乗る文書が存在する。これらは版番号を持つが、相互に矛盾する語彙定義を含み、正式な版管理下で作成されたものではない。版番号をそのまま継承すると、正式版の初版が「v6」となり、実際には存在しない互換性履歴を主張することになる。

## 決定

`01.検討資料/` の全文書を調査資料（research）として扱う。

- 正式規格の履歴は EARS-AI Core 1.0.0 から開始する。
- 旧版番号（v2、v3、v5）を正式版履歴へ含めない。
- 旧文書の記法を「旧表現」として移行表に記載し、移行対象とする。
- 旧文書は削除せず、`01.検討資料/` に読み取り専用の経緯資料として保持する。

## 理由

- 存在しない互換性保証を暗黙に主張することを避ける。
- Core 1.0.0 を初版とすることで、[07_適合性・バージョン・移行仕様.md](../../03.詳細設計/01_EARS-AI規格/07_適合性・バージョン・移行仕様.md) のセマンティックバージョニング規則を初版から一貫適用できる。
- 検討経緯の情報価値は残るため、破棄はしない。

## 代替案

1. **v6として継続**: 却下。実体のない版履歴を作る。
2. **旧文書を削除**: 却下。決定理由の追跡可能性を失う。

## 影響

- 旧文書を参照する記述は、正式版の対応箇所へリンクし直す必要がある。
- 移行ツールは旧文書を入力として受け付けるが、出力は Core 1.0.0 準拠とする。
