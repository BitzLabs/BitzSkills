# ADR-028 SDDフローの実装後検査とTASK境界の接続

## Context

簡易フローは`Intent -> Context -> Check -> Implement -> Verify -> Done`であり、`Check`は実装の前に
1回だけ置かれていた。運用設計も`bitz check`を「編集直後」としながら、フローの図では実装前に配置していた。

一方[ADR-025](ADR-025_Git基準版とcheck明示対象の確定.md)は、TASKのIDまたはTASKのファイルのパスを明示した
`bitz check`だけが、TASKの`changes`との境界の比較を行うと定めている。実装前の汎用の`bitz check`では、実装によって
新たに生じる変更のパスを`changes`と比較できず、実装後に汎用の`check`を実行しても、TASKを明示しなければ
境界を強制しない。結果として、境界の外へ変更を書いたまま、検証と完了へ到達する経路が存在した。

完全フローは「品質検査commandはSmall Flowと同じものを使う」と述べながら、図では`Check`を1箇所しか
持たず、同じ欠落を継承していた。

## Decision

1. 簡易フローの骨格を、次へ改訂する。

   ```text
   Intent -> Context -> Pre-check -> Implement -> Post-check -> Verify -> Human Review -> Done
   ```

2. `Pre-check`は実装前の`bitz check`とし、仕様文書の構文、関係、状態遷移、および既存の作業ツリーの
   不適合を確認する。`Post-check`は実装後の`bitz check`とし、実装で生じた変更集合を検査する。
3. TASKを起点とするフローでは、`Post-check`で`bitz check <TASK-ID>`を必須とし、ADR-025の明示対象の規則で
   `changes`の境界を強制する。Gitが利用できない場合は、診断`SPEC-TASK-BOUNDARY-002`（`blocked`）とし、
   暗黙に通過させない。
4. 実装後に静的検査を経ずに`Done`へ到達する経路を作らない。`Post-check`が非成功のまま、検証へ進まない。
5. `Post-check`と検証の、失敗した場合の戻り先を分類する。コンパイル、リンター、単体テスト、境界外の変更は、`Implement`へ戻す。
   仕様の矛盾、要求の意味の変更、権限の不足は自動で修復せず、人間の確認へ戻す。一時的なツールの障害は、
   同じ副作用を増やさない冪等な再実行だけを許可する。
6. 完全フローも、実装前検査、実装、実装後検査、検証の、同じ骨格を共有する。完全フロー固有のレビューの
   否決のエッジと、`Done`への接続は、`UC-FLOW-006`として別に裁定する。
   （2026-08-31追記: `UC-FLOW-006`は同日に裁定し、否決のエッジを`04_SDDプロセス設計` §3へ反映した。
   レビューの承認と否決は、Coreの機械的な契約に含めない。）
7. Coreの公開操作は追加しない。本決定はフローの配置と必須の呼出しの契約であり、`bitz check`の対象の選択の規則、
   診断、終了コードはADR-025と既存の仕様のままとする。

## Consequences

- TASKを起点とする作業で、境界の外へのコードの変更が、完了より前に必ず検出される。
- 実装の前後の`check`が別の段階として名前を持ち、運用設計の「編集直後」とフローの図が一致する。
- TASKを持たない小さな変更では、`Post-check`が汎用の`check`となり、境界の検査は行われない。境界の保証が必要な
  作業は、TASKを作る必要がある。
- 簡易フローと完全フローの検査の配置が同一になり、完全フロー専用の検査の経路を作らずに済む。

## Alternatives

1. **`Check`を1箇所のまま実装後へ移す**: 実装前の仕様文書の不適合と作業ツリーの衝突を検出できず、
   事前検査の前提が崩れるため採用しない。
2. **汎用の`check`でも常にすべてのTASKの`changes`を検査する**: 無関係な、状態が`open`のTASKの境界が現在の変更へ適用され、
   偽陽性が日常化するため採用しない（ADR-025の明示対象の規則を維持する）。
3. **境界外の変更を警告にする**: 提案資料のREADMEでTASK境界の警告化と自動承認を不採用としており、
   `blocked`を維持する方針と矛盾するため採用しない。
