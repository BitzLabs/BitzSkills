# 制約

変えられない前提であり、あえてやらない選択（対象外）とは別。対象外は
`docs/00_はじめに/対象外.md` を参照。

## 技術的制約

- 配布対象は Claude Code、Antigravity 2.0、Codex CLI の3プラットフォームのみ。
  各プラグインは3マニフェスト（`.claude-plugin/plugin.json` / `plugin.json` /
  `.codex-plugin/plugin.json`）の `version` を常に一致させる。
- スキルは Agent Skills オープン標準に準拠し、フォルダ単位で自己完結させる
  （他スキルの `references/` を相対パスで参照しない）。
- `bitz-env` の機械フック（危険操作の自動ブロック等）は現時点で Claude Code / Antigravity
  のみ対応。Codex はスキルと `AGENTS.md` の規律で運用する（差分は `SI-ENV-023` で追跡）。

## 組織的・法的制約

- 少人数（実質1名によるドッグフーディング中心）での保守を前提とし、重複責務や
  同一情報の多重記載を増やさない。
- リポジトリ外への書き込み・上書き・削除（`skill-packager` によるスキル配置を含む）は
  ユーザーの明示承認を必要とする。
- 認証情報・トークン類（`~/.claude/.credentials.json` 等）は読み取り・出力しない。

## library 固有

- 本リポジトリは `project_type: library` として扱う。互換性、配布可能性、
  プラットフォーム間の機能差は `03_設計仕様` 側の文書が管理し、ここでは前提のみを記す。
- 各プラットフォームの仕様判断は一次資料または実測を根拠にする
  （`docs/調査報告/01.Antigravity/`・`02.ClaudeCode/`・`03.Codex/` が正）。
