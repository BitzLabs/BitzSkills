# ステークホルダー・利用者

| 主体 | 関心事 | 意思決定への関与 |
|---|---|---|
| BitzLabsの開発者・標準環境メンテナ（主要） | 環境説明の再説明を減らす、危険操作・仕様乖離・Git運用ばらつきの抑止 | 承認（`docs/` への書き込み・リリース判断） |
| BitzLabsの共同開発者（served, `[proto / 未検証]`） | プロジェクト固有ルールの所在、完了条件の明確さ | 相談 |
| Claude Code / Antigravity 2.0 / Codex CLI（実行主体としてのAIエージェント） | 明確な権限境界、段階的に読めるスキル、定型スクリプト、安全な失敗停止 | 実行（人間の承認なしにdocsへ書き込まない） |

## library の想定コンシューマ像

- 対応AIエージェント（Claude Code / Antigravity 2.0 / Codex CLI）を通じて
  BitzLabsのリポジトリを開発・保守する開発者が、プラグイン単位またはプロファイル単位で
  導入する想定コンシューマ。
- 利用規模は現状ドッグフーディング中心（n=1系統）で、複数開発者・複数リポジトリでの
  実利用データは `TBD`（`.spec/discovery/personas.md` 参照）。
- アンチペルソナ: 既に別組織標準・ガードレールで統制されているチーム、OS/クラウド/IDEを
  含む端末プロビジョニング全体だけを求める利用者。
